语音提问
不方便打字时，点一下输入框旁的麦克风直接说话就行——「www 改了为什么不生效」这样的问题会自动变成文字填进对话框，边说边出字，说完还能改一改再发送。诊断助手会结合你当前看的页面回答。

生效检测
改完解析不用干等。系统会拿阿里、腾讯、Google 三个公共 DNS 真去查一遍，把每条记录的查询结果和耗时摆出来，直接给结论：已生效 / 还在 TTL 缓存里 / 域名根本没指到这家平台。省去自己开命令行 nslookup 来回试。

趋势图表
近 24 小时每个小时的同步情况，成功和失败分开画成柱状图。哪个时段出了问题、是零星失败还是整批挂了，扫一眼就看出来，不用翻几百条日志找规律。

厂商健康度
腾讯云、阿里云、火山引擎、Spaceship 四家分别统计调用量和成功率，成功率用进度条呈现，掉到 90% 以下自动标红。哪家最近不稳、上午还是晚上开始出问题，一眼定位。

一键补齐
本地和云端记录对不上时，「一致性校验」会逐平台列出到底少了哪几条，点一下就自动推过去，不用再打开云控制台一条条手动添加。反过来，云端有、本地没有的记录也能一键拉回来。

双主题
亮色、暗色一键切换，选择会被记住。白天在办公室用亮色，晚上用暗色，长时间看不累眼，手机上打开也是同一套界面
