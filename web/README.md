## 子账号与权限（面向中小企业）

跨境业务常见组合：国内一家云（阿里云）+ 海外一家（Spaceship / 火山），两边记录要一致。这类团队往往多人协作，但不该让每个人都能动所有域名。

| 角色 | 可见域名 | 能做什么 |
|---|---|---|
| 超级管理员 `admin` | 全部 | 全部功能，含云账号、子账号、审计日志 |
| 员工账号 `operator` | 仅被授权的域名 | 授权域名内增删改记录、一致性校验、生效检测、开关平台同步 |
| 只读账号 `viewer` | 仅被授权的域名 | 只能查看 |

- 员工账号**看不到**未授权域名，直接请求接口也会 403，不只是前端隐藏
- 新建域名、删除域名、管理云账号只有管理员能做
- 实现：`users.scope_all`（1=不限，兼容历史账号）+ `user_domains`（授权明细）；`ScopeGuard` 中间件统一拦截 `/api/domains/{id}/...` 与 `/api/records/{id}`

```bash

```
